Key 和 endpoint 只保存在你自己的浏览器里，只随请求发给中转服务或你填写的 Laya 服务。Jev 不允许网页直接调用（它的服务器拒绝跨域请求），所以要经过中转：线上版默认用本站作者部署的 Cloudflare Worker，它只转发、不保存 key（代码）。不放心可以换成自己的中转：本机运行 npm start，或部署一份自己的 Worker（说明）。
